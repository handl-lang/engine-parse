# Reference

## Public API

| item | what it is |
|---|---|
| `ParserEngine` | the trait a parser implements |
| `ParserRequest` | tokens + language the engine parses |
| `ParserContext` | per-parse state: arena, position, diagnostics |
| `Parser` | lexed-token cursor: `advance`, `peek`, `pos`, `tokens`, `expression` |

## Crate

| crate | role |
|---|---|
| `hnl-engine-parse` | abstraction — contract only |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # no test suite here — covered by consumers
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
